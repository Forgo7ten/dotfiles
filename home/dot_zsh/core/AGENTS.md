# AGENTS.md

## 作用域

- 本文件适用于当前目录及其子目录，并继承仓库根 `AGENTS.md`。
- Core 架构与加载流程由 `README.md` 说明；本文件只定义修改行为约束。
- `core/` 在插件管理器之前加载；这里的代码必须快速、可预测、无插件依赖，并可在每次 Zsh 启动时安全执行。仅 `40-runtime/` 可按下述约束激活已安装的运行时管理器。

## 分层放置

加载顺序固定为 `00-bootstrap → 10-env → 20-options → 30-keymap → 40-runtime`，文件只能依赖加载顺序中位于其之前的定义。

| 目录 | 允许内容 |
| --- | --- |
| `00-bootstrap/` | 后续阶段需要的基础类型、注册表与轻量辅助函数 |
| `10-env/` | 当前未放置配置内容；用于放置交互式环境所需的环境变量等配置 |
| `20-options/` | `setopt`、`unsetopt`、`zstyle` 等 Zsh 行为选项 |
| `30-keymap/` | 不依赖插件的 `bindkey` 与 ZLE 键位配置 |
| `40-runtime/` | 激活已安装、且插件管理器初始化时必须可见的运行时与工具路径 |

- 插件初始化放到 `../managers/`；依赖插件或外部工具的普通环境、别名、函数放到 `../features/`；仅插件管理器加载前必须生效的运行时激活放到 `40-runtime/`；机器差异覆盖放到 `../local/`。
- 新阶段目录沿用两位数字前缀；源文件使用 `.zsh`，需要 chezmoi 条件时使用 `.zsh.tmpl`。

## 强制约束

- 不访问网络、不安装软件、不 clone 或 source 外部仓库，不在加载时执行耗时或持久化副作用操作。
- 不调用插件命令、插件 widget 或依赖尚未加载的补全系统。
- `00-bootstrap/` 至 `30-keymap/` 不得在 shell 启动时执行外部命令；`40-runtime/` 只能在命令存在时调用已安装的运行时管理器来生成并加载当前 shell 的激活代码。
- `40-runtime/` 的激活必须快速、幂等且缺失时安全跳过；不得安装、更新或下载工具，也不得产生持久化写入。
- 可定义命令包装函数；可选命令或目录缺失时不得导致启动失败。
- 保持重复 source 安全，避免重复追加路径、重复注册或覆盖用户状态。
- OS、hostname 或 chezmoi data 差异使用 `.tmpl`；不要在共享文件中无条件假设单一平台。

## 修改与验证

- 修改前检查 `../zshrc.tmpl` 的实际加载顺序；移动文件时同时检查其前置依赖和目标层职责。
- 只做静态验证：渲染涉及的模板，并对渲染后的 Zsh 文件运行 `zsh -n`；不得以验证为由执行 `chezmoi apply`。
- 除 `40-runtime/` 已记录的 manager 前运行时激活外，变更若需要插件、外部工具或机器状态才能成立，应移出 `core/`，而不是在本目录增加兼容补丁。
